# Blaque Baux Beltway — research

Path-A research plan for the Beltway sleeve. Nothing here is run yet; this directory holds the
sketches once they land. Built to *try to kill* the "Democratic policy → stable growth" thesis, not
to flatter it.

## Planned sketches

| # | Question | Method | Status |
|---|----------|--------|--------|
| 1 | Define each era's darlings ex-ante-style | Clinton / Obama / Biden policy-favored baskets, documented-at-the-time | ☐ not run |
| 2 | Is "same-party regime" informative? | D vs. R basket returns — raw | ☐ not run |
| 3 | Does it survive controls? | Re-test controlling for Fed, cycle, market beta, valuations at inauguration | ☐ not run |
| 4 | Persistence vs. reversion | Do era darlings carry into the next administration or fade? | ☐ not run |

Small sample (few terms) and heavy confounds. A clean **null** is a perfectly good, publishable
outcome — presidents do not cause bull markets.
